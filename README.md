# А-57 Эксплуатация — Сайт + Личный кабинет

## Быстрый старт

```bash
npm install
node scripts/seed.js
npm run dev
```

Сайт: http://localhost:3000

## Доступы

| Роль | Email | Пароль |
|------|-------|--------|
| Администратор | admin@a-57.ru | Admin123! |
| Тестовый клиент | demo@client.ru | Client123! |

## Настройка email

Откройте `.env.local` и вставьте пароль от mail.ru:
```
SMTP_PASS="ваш-пароль-для-внешних-приложений"
```
Пароль создаётся в настройках mail.ru → Безопасность → Пароли для внешних приложений.

## Что входит

- Лендинг с полной информацией о компании
- Форма заявки без регистрации (отправка на email)
- Личный кабинет клиента: заявки, статусы, файлы, регламенты
- Панель администратора: все заявки, смена статусов, назначение мастеров, создание регламентов

## Деплой

```bash
npm run build && npm start
```
